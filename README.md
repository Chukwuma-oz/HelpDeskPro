# HelpDeskPro AWS CloudFormation Practice

Build and deploy an IT Support Ticket Management System.

This is a practice assignment, so the CloudFormation template is intentionally incomplete.
Complete the TODO sections yourself.

Target AWS services:
VPC, Subnet, Internet Gateway, Route Table, Security Groups, EC2, RDS MySQL,
S3, IAM Role/Instance Profile, and CloudWatch.

Phase 1: run the backend locally.
Phase 2: connect the application to MySQL.
Phase 3: complete CloudFormation.
Phase 4: deploy the stack.
Phase 5: deploy the application to EC2.
Phase 6: test the complete system.

Never commit real AWS passwords, access keys, or .env files.
